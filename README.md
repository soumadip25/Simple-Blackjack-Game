# Blackjack

A small browser-based Blackjack game built with HTML, CSS, and vanilla JavaScript. Start a round, draw cards, and try to reach 21 without going over.

## Run locally

Clone or download the repository, then open `index.html` in a web browser. No installation or build step is needed.

## How to play

- Select **Start Game** to deal two cards.
- Select **New Card** to draw another card while the game is active.
- Number cards keep their value; face cards count as 10, and an ace counts as 11.
- Reach 21 for Blackjack; go over 21 and the round ends.

The game uses `table.png` as its table background image.
